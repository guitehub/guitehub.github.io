# icomkr — petit convertisseur d'icônes

[icomkr](/projets/icomkr.html)

À QUOI ÇA SERT
--------------
icomkr transforme une image JPG ou PNG (ou WebP, GIF…) en un fichier
d'icône .ico, utilisable comme :
  - favicon d'un site web (l'icône dans l'onglet du navigateur) ;
  - icône de dossier sous Windows.

COMMENT ON L'UTILISE
--------------------
1. On glisse-dépose une image dans la page (ou on clique pour la choisir).
2. On coche les tailles à inclure dans le .ico (16, 32, 48, 256 px…).
3. Si l'image n'est pas carrée, on choisit « Marges » (ajout d'un fond,
   transparent ou coloré) ou « Rogner » (recadrage au centre).
4. On clique sur « Générer le .ico » et le fichier se télécharge.

Un seul .ico est produit, contenant toutes les tailles choisies à la fois,
comme l'exige le format.

SUR QUELLE TECHNO C'EST BÂTI
----------------------------
C'est une page web autonome, en un seul fichier (icomkr.html) :
HTML + CSS + JavaScript, sans aucune dépendance ni bibliothèque externe.

Tout se passe directement dans le navigateur — aucune image n'est envoyée
sur un serveur, donc ça fonctionne aussi hors-ligne :
  - l'image est dessinée et redimensionnée pour chaque taille via l'élément
    < canvas > du navigateur, puis exportée en PNG ;
  - le fichier .ico est ensuite assemblé « à la main » en JavaScript, en
    écrivant directement les octets du format ICO (en-tête + table des
    images + données PNG empilées).

L'habillage visuel reprend les couleurs, polices et le mode clair/sombre du
blog « Le Hub de la Guite » pour s'intégrer comme une page du site.
