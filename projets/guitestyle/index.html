guitestyle v1.0.0

Le socle de style du Hub de la Guite : des variables CSS et une base typographique, à charger dans n'importe quel projet pour en reprendre l'allure.

Utiliser

En direct : le projet suit chaque modification publiée sur le site.

<link rel="stylesheet" href="https://guitehub.github.io/assets/guitestyle/tokens.css">
<link rel="stylesheet" href="https://guitehub.github.io/assets/guitestyle/base.css">

Figé sur une version : rien ne bouge tant que le projet ne change pas de tag.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/guitehub/guitehub.github.io@guitestyle-v1.0.0/assets/guitestyle/tokens.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/guitehub/guitehub.github.io@guitestyle-v1.0.0/assets/guitestyle/base.css">

Garder ses propres couleurs, et prendre le reste :

:root { --accent: #2a7; }

Le thème suit le système. Pour le forcer : data-theme="light" ou data-theme="dark" sur <html>.

Couleurs

Les valeurs affichées sont celles du thème en cours.

VariableRôleValeur

Base

base.css règle le corps du texte, les liens, la sélection, les images, les filets et le code, comme <code> en ligne ou un bloc :

body { font-family: var(--sans); color: var(--fg); }

Aucune classe, aucune mise en page : chaque projet garde les siennes.
